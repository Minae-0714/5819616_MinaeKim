# 결과 분석 
### ▪ A, B, C에 대해서 퀵 정렬후의 이진탐색에서 순차탐색보다 적게 비교하는 이유를 설명

이진 탐색은 정렬된 배열에서 작동하는 알고리즘으로, 중간 값을 기준으로 탐색 범위를 절반으로 줄여 나가는 방식이다. 하지만 순차 탐색은 배열의 처음부터 끝까지 모든 요소를 비교해야 하므로 비교 횟수가 많아진다.
순차 탐색은 배열의 크기에 비례하여 비교 횟수가 증가하는 반면(O(N)), 이진 탐색은 로그의 비율로 증가한다. (배열 크기에 대해 O(log N)의 시간 복잡도를 가짐) 이는 데이터의 양이 많아질수록 이진 탐색의 효율성이 증가한다.
